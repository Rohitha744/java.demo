What is Java!!!

Java is a versatile, object-oriented programming language, known for its platform independence
and use in various applications like Android apps, web applications, and enterprise software.
It was developed by Sun Microsystems (now owned by Oracle)in 1995 and is designed to be
"write once, run anywhere" through the Java Virtual Machine (JVM).

Key Features of Java:
Object-Oriented:

Java is built around the object-oriented programming paradigm, allowing for modular and
reusable code through classes, objects, inheritance, and polymorphism.

Platform Independence:

Java applications can run on any device with a JVM installed, making it highly portable.

Automatic Memory Management:

Java's garbage collector automatically manages memory allocation and deallocation, reducing
the need for manual memory management and potential errors.
